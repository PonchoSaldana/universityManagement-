NOMBRE DEL PROYECTO: ESCUELA
Versión: 0.0.0

================================================================================
¿QUÉ ES?
================================================================================

Es una aplicación web de gestión escolar que permite a estudiantes, maestros y 
administradores interactuar dentro de un sistema integral de educación. 

La plataforma funciona con una arquitectura de dos capas:
- FRONTEND: Aplicación React con Vite
- BACKEND: Servidor Node.js Express con base de datos MySQL


================================================================================
FUNCIONALIDADES PRINCIPALES
================================================================================

1. AUTENTICACIÓN Y ROLES DE USUARIO
   - Login de usuarios (estudiantes, maestros, administradores)
   - Sistema de autenticación basado en credenciales
   - Control de acceso según rol del usuario

2. DASHBOARD POR ROL
   
   ESTUDIANTES:
   - Ver mis clases/asignaturas inscritas
   - Consultar calificaciones (parciales y finales)
   - Ver próximas clases
   - Revisar anuncios y materiales de estudio
   - Acceso a materiales de clase
   
   MAESTROS:
   - Gestionar mis clases
   - Ver lista de estudiantes por clase
   - Registrar y actualizar calificaciones (P1, P2, P3 y finales)
   - Publicar anuncios para los estudiantes
   - Compartir materiales educativos
   
   ADMINISTRADORES:
   - Gestión completa de clases
   - Gestión de estudiantes (inscripciones, eliminación)
   - Gestión de maestros
   - Gestión de usuarios y roles
   - Configuración del sistema
   - Ver anuncios y reportes

3. GESTIÓN DE CALIFICACIONES
   - Sistema de tres parciales (P1, P2, P3)
   - Cálculo automático de promedio
   - Calificación final
   - Validación automática (aprobado >= 6, reprobado < 6)

4. GESTIÓN DE CONTENIDO
   - Anuncios escolares
   - Materiales educativos
   - Recursos por clase

5. TEMAS Y PERSONALIZACIÓN
   - Sistema de tema oscuro/claro
   - Interfaz responsive
   - Animaciones fluidas (Framer Motion)


================================================================================
TECNOLOGÍAS UTILIZADAS
================================================================================

FRONTEND:
- React 19.2.0 - Librería para interfaz de usuario
- Vite 7.2.4 - Herramienta de construcción rápida
- React Router DOM 7.9.6 - Enrutamiento de aplicación
- Framer Motion 12.23.24 - Animaciones
- Lucide React 0.554.0 - Iconografía
- ESLint - Linter para código limpio

BACKEND:
- Node.js - Entorno de ejecución de JavaScript
- Express.js - Framework web
- MySQL - Base de datos relacional
- Nodemon - Desarrollo en tiempo real

BASE DE DATOS:
- Tablas principales: usuarios, estudiantes, maestros, clases, 
  inscripciones, calificaciones, anuncios, materiales

================================================================================
REQUISITOS PARA EJECUTAR
================================================================================

1. Node.js instalado en la máquina
2. MySQL (se recomienda Laragon)
3. Conectar a base de datos "escuela_db"
4. Ejecutar scripts de inicialización

COMANDOS:
npm run dev           - Inicia el desarrollo
npm run build         - Construye para producción
npm run lint          - Verifica código
node setup_db.js      - Inicializa la base de datos


================================================================================
FLUJO DE USUARIO TÍPICO
================================================================================

1. Usuario llega a la página de login
2. Ingresa credenciales (usuario/contraseña)
3. El sistema valida contra la BD MySQL
4. Si es correcto, se redirige al dashboard según su rol
5. Accede a funciones específicas de su rol
6. Los datos se cargan desde la API backend
7. Puede realizar acciones (ver, crear, editar, eliminar)


================================================================================
OBJETIVO GENERAL
================================================================================

Proporcionar a escuelas una plataforma digital integrada donde estudiantes 
puedan consultar sus calificaciones, maestros puedan gestionar sus clases, 
y administradores tengan control total del sistema educativo.
